本手册的原始内容来自 [BeanDesk](https://github.com/SuperDaniel-cn/BeanDesk)（作者：SuperDaniel-cn），按 **AGPL-3.0** 发布。本仓库是在其基础上的二次扩展。

> 原则：**原作者的构思、原有章节与许可证保持不变**；本页单独列出我们做的改动，便于对照、审计与致谢。

## 我们改了什么

### 1. 会计期间

- 顶栏只保留四个纯图标；点击日历打开统一的「会计区间」面板；
- 支持按年、季度、月份或自定义起止日期选择，先选后「应用」；
- 有筛选时，日历左侧出现「清除期间」按钮（FilterX），清除后回到全部期间；
- 各报表与日记账在内容头部常驻「筛选期间 · …」，时点余额另标「截至 …」。

### 2. 图表

- 新增净值、现金流、储蓄率、支出构成、收款方等趋势；
- 资产配置支持「资产类别 / 大类 / 明细账户」三种维度；
- 分类颜色按类别稳定绑定，切换期间或排序不再换色；
- 环图与树图提供可折叠的「查看明细」，可用键盘读取名称与金额；
- 空期间、加载失败、未折算币种分别有独立提示；失败时 KPI 不再显示 0。

### 3. 金额与精度

- 货币符号固定：人民币 `¥`、美元 `US$`，不随界面语言变化；
- 加密货币按单位保留精度（BTC/ETH 最多 8 位，USDT/USDC 2 位），不再把 `0.00012345 BTC` 显示成 `0.00`；
- 汇总与明细区分「真零」「未取得数据」「无法计算」三种状态。

### 4. 界面与可访问性

- 统一报表与日记账的表头、行高、数字对齐；正文 14px、轴字 12px；
- 设置中新增「界面密度：舒适 / 紧凑」，选择会记住；
- 主色统一为靛蓝；分类色与涨跌红绿分离；
- 轴字与树图标签按底色取色，满足 4.5:1；支持 `prefers-reduced-motion`；
- 期间弹窗修复焦点锁定，键盘 Tab 不会跑到背后页面；
- 使用手册窗口支持 Esc 关闭。

### 5. 投资组合与账户

- 投资组合作为独立区块，支持目标占比、快速全选/清空；
- 账户名支持中文标签 / 原始路径切换、拼音搜索、CSV 导出路径。

## 范围说明

- 本分支**不包含日历页**；原手册的「日历」章节保留，仅作上游参考。
- 期间「清除」按钮最终保留在顶栏日历左侧（早期评审曾建议收进弹窗，后按实际使用恢复）。

## 没有改什么

- Beancount 账本文件格式与目录约定；
- 原有的数据存储、备份、连接与 MCP 能力；
- 原作者的许可证、版权声明与原始手册章节。

## 构建与验证

```bash
make install
make dev            # 前端
make docs-sync      # 把本手册导出到 web/public/docs
cd web && bun test && bunx tsc -p tsconfig.app.json --noEmit
```
