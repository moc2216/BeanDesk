# ADR 0002 · 分类色与对比度

状态：已采纳（2026-11-26）

## 背景

原分类色在浅色卡片上有 2 个颜色低于 3:1；颜色按金额排名分配，换期间会换色。

## 决策

- 颜色绑定类别键（`assetClass:*`、`expense:*`、`rollup:other`），不绑定排名；
- 分类色对 #FFFFFF 与 #16181D 均 ≥3:1；块内文字 ≥4.5:1；
- 主色靛蓝保留；红绿只用于涨跌；
- 暖色只用于小面积类别，避免大面积土色。

## 影响

- `web/src/lib/chart-theme.ts` 的 `CATEGORY_COLORS` 是唯一映射；
- 新增类别必须同时给键与缺省色（石板灰）；
- 改色需附对比度计算与浅/深截图。

## v3 修订（2026-11-27）

用户评审后改为「Apple 外壳 + 高彩度数据色」：

- 画布 #FAFAF8（深色 #161617），卡片 #FFFFFF / #1F1F21，发丝线 #ECECEA / #2C2C2E；
- 强调色 #0968EF（深色 #4C9AFF），只用于选中态、链接与主按钮；
- 数据色改为等明度 L≈0.66、彩度 0.16 的一组：#4693F1 #00A8CF #00B08D #A975E0 #CC68B9 #DA720D #7787F3 #8B939F；
- 树图不再在块内塞小字，改为图例 + tooltip；资产构成按资产类别取色；
- 报表 KPI 与图表 KPI 统一为 34px 数字、16px 圆角卡片。

此版取代原 B 色板与低彩度方案。
