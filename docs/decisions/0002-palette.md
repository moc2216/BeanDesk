# ADR 0002 · 分类色与对比度

状态：已采纳（2026-11-26）

## 背景

原分类色在浅色卡片上有 2 个颜色低于 3:1；颜色按金额排名分配，换期间会换色。

## 决策

- 颜色绑定类别键（`assetClass:*`、`expense:*`、`rollup:other`），不绑定排名；
- 分类色对 #FFFFFF 与 #16181D 均 ≥3:1；块内文字 ≥4.5:1；
- 主色靛蓝保留；红绿只用于涨跌；
- 暖色只用于小面积类别，避免大面积土色。

## 影响

- `web/src/lib/chart-theme.ts` 的 `CATEGORY_COLORS` 是唯一映射；
- 新增类别必须同时给键与缺省色（石板灰）；
- 改色需附对比度计算与浅/深截图。
