# ADR 0003 · 会计期间交互

状态：已采纳（2026-11-26）

## 背景

期间选择分散、点选即生效、顶栏图标会跳位；清除入口一度被移除。

## 决策

- 顶栏固定四个纯图标，日历打开统一「会计区间」面板；
- 年/季/月/自定义区间，先选后「应用」；
- 有筛选时，日历左侧出现 FilterX 清除按钮；右对齐布局保证其它图标不移动；
- 报表与日记账在内容头部常驻「筛选期间」。

## 影响

- `web/src/components/time-filter-selector.tsx`；
- 不要在 DialogContent 上阻止 autofocus（会破坏焦点锁）。
