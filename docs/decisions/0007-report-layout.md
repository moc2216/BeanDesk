# ADR 0007 · 报表页版式

状态：已采纳（2026-11-28）

## 背景

参考设计「资产负债表.webp」表明：财务报表页的核心是“总量 → 明细 → 结构 → 现金流”，
四张浮卡会把表格推低，也不利于纵向比较。

## 决策

- 资产负债表、利润表、现金流量表采用“摘要带 + 表格主角 + 右栏”；
- 摘要带为连续白底，四格用 1px 竖线分隔，数字 20px；
- 右栏 320px：资产构成环图 + 现金流摘要（未配置货币资金账户时显示提示）；
- 卡片圆角统一 12px；报表表格 13px；
- 图表页保留 KPI 卡片与图表，因为图表页的任务是“看趋势”，不是“读分录”。

## 影响

- BalanceSheet.tsx 的 OverviewStrip 为摘要带；AssetComposition 图例单列、颜色按
  assetClass:* 绑定；CashFlowMini 复用 fetchCashFlow；
- 其他报表页沿用同一套 tokens；
- 新增报表页时优先沿用该版式，不要默认四张卡片。
