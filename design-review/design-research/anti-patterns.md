# BeanDesk 设计宪章 · 视觉反例

下列“廉价感／过时感”均为 **判断**。识别条件描述的是可指认的画面特征，替代做法以[设计原则](principles.md)为准。

| # | 可指认的特征 | 为什么显得廉价或过时（判断） | 替代做法 |
| --- | --- | --- | --- |
| 01 | 同一块 KPI 同时出现粗边、重阴影、高光和大圆角 | 每种效果都把卡片推向前景，金额的层级反而被削弱。 | 用一层中性表面与细边，只有确实盖在内容之上的弹窗才加阴影。R01、R04 |
| 02 | 每张金额卡都铺不同的高饱和渐变 | 色变像是在编码差异，读者却找不到这些差异的含义。 | 卡片使用同一底色。渐变可用于有色带刻度的连续量编码，核对端点和文字对比。R08、R09 |
| 03 | 固定顶栏做成透出滚动账目文字的玻璃层 | 背景文字一直变化，容易在工具和导航下方形成第二层信息。 | 顶栏用稳定表面。轻透明可以保留，条件是滚动过图表和表格时文字对比稳定、背景无法干扰阅读。R05、R09 |
| 04 | 轴字、金额单位和表头统一用极淡小号灰字 | 关键读数变成类似占位文字的层级，页面像一个未填充的模板。 | 普通字保持 4.5:1，轴字和表头至少 12 px。弱化首先用大小和字重，色值以实测为准。R02、R09 |
| 05 | 每个标签、日期、操作和状态都包成胶囊 | 相同外形同时暗示筛选、按钮和纯文本，成排轮廓也会抢占借贷读数线。 | 让可操作的分段控件或需要辨识的状态使用胶囊，普通日期、单位和注释保持纯文本。R05、R06、R10 |
| 06 | 中文小标签大幅加字距，多个字号同屏细微递增 | 汉字词组容易被视觉拆开，多个近似字号又无法说明结构。 | 中文用默认字距，按照表头、正文、区块、页标题和指标的字级切换。R02 |
| 07 | 金额居中、统一小数位，窄列用省略号盖住币种 | 看起来像居中陈列的卡片，读者难以横向核对真实数值。 | 同单位金额用等宽数字右对齐。混合币种保留代码与有效位，空间紧时先让科目换行。R03、R06 |
| 08 | 账表每个单元格都描深色边，展开行再铺浓底 | 网格和状态块覆盖了实际科目层级，读数成本像在逐格找坐标。 | 以横线、缩进、字重区分小计。长表可淡条纹，借贷分界有明确的分组用途时保留竖线。R01、R06 |
| 09 | 构成图按大小换彩虹色，相邻小块依靠近似色分割 | 色彩没有可复用的类别含义，切期间就像换了一张图表模板。 | 固定类别映射。无独立展示需要的小类别可归“其他”，提供边界、外标和明细。R07–R09 |
| 10 | 3D 柱、厚投影、每个刻度的网格线同时出现在小图里 | 视觉深度改变读者对长度、面积的判断，密集网格又和数据线争抢。 | 用二维刻度，只留下辅助读数的网格和零线。宽图可以保留稀疏网格来对应金额。R07 |
| 11 | 深色主题的画布、卡片和弹窗全用同一黑底，再用亮描边硬切 | 表面之间没有稳定的层次，看起来像随处加框的临时主题。 | 为画布、卡片、浮层各配中性表面与前景色。强调边框主要用于焦点与状态。R08、R09 |
| 12 | 空状态先放大插画、闪烁占位和大号欢迎语，原因在下方小字 | 情绪装饰占据了本应用来说明连接、筛选或读取状态的位置。 | 优先放状态标题、短原因和一个可执行动作。插画只有在引导确实需要定位时使用，加载可用静态占位。R11、R12 |

## 上线前设计检查清单

用同一套测试数据核对浅色和深色主题。按[原则](principles.md)的参考窗口复查窄窗、缩放和英文导航。保留截图、对比值或实际操作结果，作为逐项勾选的依据。

- [ ] 顶栏、页标题、KPI 组与表格对齐，组内与组间用约定间距。
- [ ] 中文正文、标签和图表轴字符合字号与行高，长说明能自然换行。
- [ ] 金额显示币种或品种、适用期间，时点余额和期间比率有明确区分。
- [ ] 用 CNY、USD、BTC 和长证券代码验证金额不截断，小额明细保留有效位。
- [ ] 用未定价币种测试净资产与构成图，能就地看出部分折算及受影响范围。
- [ ] 图表首屏最多 4 张 KPI 卡与 3 个图表模块，净资产和主趋势可先读到。
- [ ] 看得到当前页与已选期间。窄窗和英文导航不会互相重叠或遮挡工具。
- [ ] 仅用键盘可切期间、识别焦点、展开数据和读取凭证。常用热区符合尺寸目标。
- [ ] 用舒适和紧凑两档检查表格行高、长表列头、金额对齐与借贷顺序。
- [ ] 趋势有适用的零线和单位，金额排名可按同一尺度或表格比较。
- [ ] 构成图最多 8 个首屏类别，期间切换保持同类同色，“其他”可展开。
- [ ] 环图和树图可用键盘读取名称、金额、占比，名称与方向不靠颜色猜测。
- [ ] 实测普通字 4.5:1、大字 3:1。验证轴字、叶节点混色、提示框与选中态文字。
- [ ] 分类色对两种规定卡片底色均 ≥3:1，必要图形、边界和焦点也按实际相邻色检查。
- [ ] 桌面设置有清楚的分区、状态与主操作。连接切换及写入操作有对象明确的确认。
- [ ] 验证加载、真零、无定义比率、空结果与错误。每种状态有对应文案和恢复路径。
- [ ] 开启减少动态效果，切期间、加载和展开分录均可静态完成，金额无数值滚动。
